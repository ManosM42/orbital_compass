# Orbital Compass

Build the complete premium ORBITAL satellite-tracking frontend described by the user. Implement responsive React/TypeScript/Tailwind UI with cinematic home, interactive mock 3D-style Earth/globe experience, tracker, above-me, passes, Starlink, ISS, pricing, nav, bottom mobile nav, realistic mock data/data interfaces, search/filter/favorites and animated polished visual design. Ensure navigation and interactions work. Use the supplied content and visual direction closely. Use mock satellite orbital data structured for future satellite.js/API replacement.
